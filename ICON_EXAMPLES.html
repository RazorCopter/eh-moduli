11. Best Practices

✓ DO
  • Always specify icon size
  • Use color classes not inline styles
  • Pair icons with text for clarity
  • Use semantic colors
  • Test icon visibility on backgrounds
✗ DON'T
  • Use undefined icon sizes
  • Use inline color styles
  • Use icons without text context
  • Use colors inconsistently
  • Assume sufficient contrast
